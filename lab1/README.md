## Цель работы

## 1. Теоретический минимум

### Задача оптимизации

Во многих задачах машинного обучения необходимо найти параметры модели, при которых функция потерь принимает минимальное значение:

$$
\theta^* = \arg\min_\theta L(\theta).
$$

Здесь $\theta$ - параметры модели, а $L(\theta)$ - функция потерь.

### Градиентный спуск

Градиент показывает направление наиболее быстрого увеличения функции. Чтобы уменьшать функцию, мы двигаемся в противоположном направлении:

$$
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t),
$$

где $\eta$ —-**learning rate**, или шаг обучения.

Слишком маленький шаг может приводить к медленной сходимости, а слишком большой - к колебаниям или расходимости.

## 3. Часть B. Линейная регрессия с нуля

Теперь применим оптимизацию к обучению модели.

Линейная регрессия предсказывает значение по формуле

$$
\hat y = wx + b,
$$

где $w$ и $b$ — параметры модели.

Для обучения используем среднеквадратичную ошибку:

$$
L(w,b) = \frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.
$$

### Задание B1. Подготовка данных

Сгенерируйте синтетический набор данных по формуле

$$
y = 2x + 1 + \varepsilon,
$$

где \(\varepsilon\) — случайный шум.

Используйте не менее 100 объектов. Зафиксируйте random seed для воспроизводимости.

Постройте график полученных данных.

### Задание B2. Функция потерь и градиенты

1. Реализуйте предсказание линейной регрессии.
2. Реализуйте MSE.
3. Аналитически выведите производные функции потерь по \(w\) и \(b\).
4. Реализуйте вычисление градиентов.

### Задание B3. Обучение модели

Реализуйте обучение линейной регрессии с помощью градиентного спуска.

Во время обучения сохраняйте:

* значения \(w\) и \(b\);
* значение функции потерь на каждой итерации.

Постройте график функции потерь и график данных вместе с полученной прямой регрессии.

Сравните найденные параметры с параметрами, использованными при генерации данных.
