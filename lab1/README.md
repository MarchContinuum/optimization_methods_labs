# Лабораторная работа №1

## Одномерный поиск и градиентный спуск

## Цель работы

Изучить методы поиска минимума функции одной переменной, сравнить их по точности и количеству вычислений целевой функции, а затем реализовать градиентный спуск и применить его к обучению простой модели машинного обучения.

## 1. Теоретический минимум

### Одномерная оптимизация

Задача одномерной оптимизации состоит в поиске точки $x^*$, в которой функция принимает минимальное значение на заданном отрезке:

$$
x^* = \arg\min_{x\in[a,b]} f(x).
$$

В этой работе рассматриваются **унимодальные функции**, для которых на отрезке поиска имеется один минимум. Это позволяет последовательно сужать интервал, содержащий точку минимума.

### Методы поиска

**Метод дихотомии** сравнивает значения функции в двух точках, расположенных около середины текущего интервала, и отбрасывает часть интервала, в которой минимум находиться не может.

**Метод золотого сечения** выбирает точки так, чтобы на следующей итерации можно было повторно использовать одно из уже вычисленных значений функции.

**Метод Фибоначчи** использует заранее известный бюджет вычислений функции и последовательность чисел Фибоначчи для выбора точек поиска.

### Градиентный спуск

Если производная функции известна, можно использовать градиентный спуск:

$$
x_{t+1}=x_t-\eta f'(x_t),
$$

где $\eta$ — learning rate, или шаг обучения.

Для функции нескольких переменных обновление записывается как

$$
\theta_{t+1}=\theta_t-\eta\nabla L(\theta_t).
$$

## 2. Часть A. Методы одномерного поиска

### Задание A1. Целевая функция

Получите у преподавателя номер варианта и соответствующие:

* целевую функцию $f(x)$;
* отрезок поиска $[a,b]$;
* требуемую точность $\Delta$.

Варианты приведены в [отдельном файле](variants.md).

Перед запуском алгоритмов убедитесь, что функция является унимодальной на заданном отрезке. Постройте её график и укажите предполагаемое расположение минимума.

### Задание A2. Метод дихотомии

Реализуйте метод дихотомии для поиска минимума функции на отрезке $[a,b]$ с точностью $\Delta$.

Функция должна принимать целевую функцию, границы интервала, точность и необходимые параметры метода.

Сохраняйте:

* текущий интервал поиска;
* точки, в которых вычисляется функция;
* количество вычислений целевой функции;
* итоговую точку и значение функции.

### Задание A3. Метод золотого сечения

Реализуйте метод золотого сечения.

При реализации используйте повторно уже вычисленное значение функции, когда соответствующая точка сохраняется на следующей итерации.

Сохраняйте те же характеристики, что и для метода дихотомии.

### Задание A4. Метод Фибоначчи

Реализуйте метод Фибоначчи.

Сначала определите количество вычислений функции, потребовавшееся методу золотого сечения. Затем запустите метод Фибоначчи с таким же бюджетом вычислений.

Сравните достигнутую точность двух методов.

**Важно:** при сравнении необходимо учитывать именно количество вычислений целевой функции, а не только количество итераций.

## 5. Часть D. Применение в машинном обучении

### Задание D1. Данные

Сгенерируйте синтетический набор данных:

$$
y=2x+1+\varepsilon,
$$

где $\varepsilon$ — случайный шум.

Используйте не менее 100 объектов и зафиксируйте random seed.

### Задание D2. Линейная регрессия

Реализуйте модель

$$
\hat y=wx+b
$$

и функцию потерь MSE:

$$
L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.
$$

Аналитически выведите и реализуйте градиенты по $w$ и $b$.

### Задание D3. Обучение

Обучите модель с помощью собственного градиентного спуска.

Постройте:

* график функции потерь;
* график данных и полученной прямой регрессии.

Сравните найденные параметры с параметрами, использованными при генерации данных.

Кратко объясните, что в этой задаче является параметрами модели, функцией потерь и результатом оптимизации.
